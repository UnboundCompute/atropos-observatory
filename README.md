# Atropos Observatory

The searchable, human-readable reference for [Atropos](https://github.com/UnboundCompute/atropos) security semantics.

## Run locally

```bash
npm install
npm run dev
```

The data step reads the sibling `../atropos` checkout. Build a static site with `npm run build`; output is written to `out/`.
