# Atropos Observatory — Field Manual System

## World
Observatory reads like a maintained technical standard: warm archival paper, precise black typography, compact red notation, and structured registers. It is a reference work, not a SaaS landing page.

## Palette
- Paper: `#f0eee7`
- Ink: `#181916`
- Muted ink: `#66675f`
- Rule: `#c9c5b9`
- Safety red: `#ad3828`
- Source blue: `#316b78`
- Sanitizer green: `#3f7056`
- Summary violet: `#65577a`

Color is reserved for semantic classification and active focus. Surfaces remain paper and ink.

## Typography
Source Serif 4 carries editorial headings and explanatory prose. IBM Plex Sans carries navigation and interface copy. IBM Plex Mono is restricted to symbols, paths, identifiers, and measurements.

## Composition
Square geometry, hairline rules, registers, and tables. No floating pills, glass, grain, gradients, bento cards, oversized hero metrics, eyebrow labels, or decorative iconography.

## Interaction
Focus is always visible in safety red. Rows translate by two pixels on hover; controls change through ink weight and underline. Motion is brief and functional.

## Direction contract

- Seed: `6425f7f2`; user-pinned replacement direction over the assigned roll.
- World: a maintained security field manual built from archival paper, typeset registers, and editorial marginalia.
- First viewport: identity and network navigation, the product statement, current pack record, then immediate symbol search and semantic-role entry points.
- Form: square geometry, hairline rules, flat surfaces, and dense tables; no cards or decorative effects.
- Signature interaction: search resolves model symbols into compact register rows, with semantic role visible before navigation.
- Motion: short horizontal row response using exponential ease-out; reduced-motion retains the state change without translation.
- Reach: the same register grammar governs browse pages, symbol records, provenance, and future language/kind indexes.
