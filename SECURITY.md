# Security policy

Atropos Observatory is a static reference site. It does not itself execute user code or certify that a modeled boundary is exploitable.

Please do not disclose private vulnerability details in a public issue. Use [GitHub private vulnerability reporting](https://github.com/UnboundCompute/atropos-observatory/security/advisories/new) when available. If the report concerns the analyzer or model pack, send it to the [Atropos repository](https://github.com/UnboundCompute/atropos/security/advisories/new).

Include the affected URL or file, reproduction steps, impact, and any relevant logs. We prioritize issues affecting generated content, build validation, security guidance, or accidental exposure of secrets.
